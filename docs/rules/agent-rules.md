# Rules for AI Agents

## Core Principles

1. **Workflow Adherence**
   - ALWAYS use `@ui-workflow.md` when beginning or continuing implementation of UI-focused feature phases
   - ALWAYS use `@backend-workflow.md` when beginning or continuing implementation of backend-focused feature phases
   - Follow workflows step-by-step, in order, without skipping sections
   - Document progress and decisions in the workflow files

2. **Code Quality Validation**
   - ALWAYS validate any changes to the codebase against `@codebase-best-practices.md`
   - Ensure all code changes follow:
     - File size limits
     - Documentation standards
     - Project structure guidelines
     - Code organization rules
     - Testing requirements
     - Performance considerations

## Implementation Guidelines

### Starting New Features
1. Begin by identifying the appropriate workflow template:
   - UI features → `@ui-workflow.md`
   - Backend features → `@backend-workflow.md`

2. Copy the workflow template and fill in:
   - Project phase
   - Primary feature details
   - Component features breakdown

3. Review all referenced documentation before starting implementation

### During Implementation
1. Follow the workflow phases in order:
   - Understanding
   - Planning
   - Implementation
   - Verification
   - Completion

2. Continuously validate against `@codebase-best-practices.md`:
   - Code structure
   - Documentation
   - Testing
   - Performance
   - Integration guidelines

### Quality Assurance
1. Use workflow checklists to ensure completeness

2. Verify all changes against:
   - Project structure requirements
   - Documentation standards
   - Testing requirements
   - Performance guidelines

3. Document all decisions and learnings in the workflow file

## Best Practices

1. **Documentation**
   - Keep workflow files up-to-date
   - Document all key decisions
   - Maintain clear progress status

2. **Validation**
   - Regular checks against best practices
   - Continuous workflow adherence
   - Quality assurance at each step

3. **Communication**
   - Clear progress updates
   - Documentation of blockers
   - Tracking of completed items
